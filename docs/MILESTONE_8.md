# Milestone 8 — Polish

Milestone 8 prepares the validated controller for source publication and later side-loaded distribution without changing its privileged fan-control boundary.

## Product polish

- [x] Compact preset and Manual-control hierarchy with non-truncated labels.
- [x] Multiline status cards for monitoring, Helper, preset, and restore errors.
- [x] Retry actions for read-only refresh and Helper connection checks.
- [x] Accurate active-mode title and lightweight temperature/RPM numeric transitions.
- [x] Native Light and Dark Mode behavior with semantic system colors.
- [x] Settings tabs for General, Hardware, Helper, and About.
- [x] Repeated Settings clicks reactivate and raise the existing Settings window.
- [x] Visible version, build, minimum macOS, license, and verified-control model.
- [x] Launch at Login and all four menu bar presentation modes retained.

## Repository polish

- [x] README features, support policy, installation status, safety, and development workflow.
- [x] `SUPPORTED_MACS.md` with an explicit Tested/Monitor Only policy.
- [x] `CONTRIBUTING.md` with elevated review requirements for safety-sensitive changes.
- [x] `SAFETY.md` updated for all three presets and distribution safety.
- [x] Final optimized build, static analysis, code-signing, and plist checks.
- [x] Real-app visual checks for the menu bar panel and all Settings tabs.
- [x] Five-minute final-code read-only soak after the final build.

## Distribution boundary

Phase 8 does not claim that an Apple Development or ad-hoc artifact is a public release. The source repository can be published without a paid account. A normal downloadable binary remains gated on Developer ID signing, notarization, and clean-Mac installation testing.
