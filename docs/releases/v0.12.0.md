# Breeze v0.12.0

Breeze v0.12.0 completes the first Full Automatic control policy for the verified 2021 14-inch M1 Pro MacBook Pro (`MacBookPro18,3`).

## Highlights

- A quieter nonlinear automatic plan: 45/20%, 60/25%, 70/45%, 80/70%, 85/85%, and 90/100%.
- Up to 5 °C of bounded planning lead when CPU/GPU temperature rises rapidly.
- Safe 5% Helper targets, immediate increases, and delayed hysteretic decreases.
- Optional login/wake Full Automatic resume, disabled by default.
- Advanced Custom curves, fixed presets, watchdog recovery, history, localization, and diagnostic export remain available.

## Sideload installation

1. Download `Breeze-0.12.0-macos-arm64.zip` and `Breeze-0.12.0-macos-arm64.zip.sha256` from the release.
2. Verify the archive with `shasum -a 256 -c Breeze-0.12.0-macos-arm64.zip.sha256`.
3. Extract the archive and move `Breeze.app` to `/Applications`.
4. On first launch, Control-click `Breeze.app`, choose **Open**, then confirm **Open**. The package is Apple Development signed but is not Developer ID signed or notarized.
5. Open **Breeze → Settings → Helper → Install Helper** and approve the macOS administrator/background-item prompts. Breeze never receives or stores the password.
6. Confirm that Settings reports Helper `v0.12.0` before enabling fan control.

Gatekeeper behavior can vary by macOS version because this is an unnotarized community sideload. Do not bypass security prompts with system-wide Gatekeeper changes.

## Compatibility and safety

- Apple Silicon and macOS 12.0 or newer.
- Fan writes remain restricted to the verified `MacBookPro18,3` two-fan model.
- Quit, sleep, Helper loss, watchdog expiry, or failed verification restores Apple Automatic.
- Full Automatic resume is opt-in and never resumes Manual, Balanced, Cool, Max, or Advanced Custom control.

Read [Installation and Recovery](../INSTALLATION_AND_RECOVERY.md) and [Safety](../../SAFETY.md) before enabling fan control.
