# Breeze v0.8.0

Breeze v0.8.0 is the first source-release candidate of the native Apple Silicon menu bar fan controller.

## Highlights

- Native temperature and fan monitoring with four menu bar display modes.
- Balanced, Cool, Max, and per-fan Manual controls on the verified `MacBookPro18,3`.
- A narrow privileged Helper that accepts only predefined fan operations.
- A 15-second Helper-owned safety lease with automatic recovery after GUI loss, XPC loss, Helper restart, sleep, wake, reboot, and failed verification.
- Native Settings, Launch at Login, Light/Dark Mode, accessible controls, and polished status feedback.

## Hardware support

Fan control is enabled only on the exact tested two-fan `MacBookPro18,3` configuration. Other Apple Silicon Macs remain Monitor Only until independently verified. See [SUPPORTED_MACS.md](../../SUPPORTED_MACS.md).

## Downloads

This release publishes source only. It does not provide a general-purpose fan-control `.app`, `.dmg`, or installer because Developer ID signing, notarization, and clean-Mac installation testing are not yet available.

Developers can build locally by following [Installation and Recovery](../INSTALLATION_AND_RECOVERY.md). An ad-hoc build must not be presented as having a functional privileged Helper.

## Validation

- Debug and optimized Release test suites pass.
- Release static analysis and strict deep code-signing checks pass locally.
- Real-hardware preset, watchdog, crash, sleep/wake, Helper restart, and reboot behavior is recorded in the milestone validation documents.
- The final Phase 8 build passed a 300-sample read-only soak on `MacBookPro18,3`.

## Known limitations

- AppleSMC interfaces are undocumented and may change with macOS or hardware revisions.
- Only Apple Silicon is in scope.
- Automatic temperature-based fan curves and historical charts are outside the v0.8.0 scope.
- Public binary distribution remains blocked on Developer ID signing and notarization.
